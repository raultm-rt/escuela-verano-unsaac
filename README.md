# Escuela de Verano en Matemática · UNSAAC Cusco 2027 — Revisión 3

Sitio estático multipágina en español, actualizado a las decisiones de noviembre de 2026.

## Archivos
Abrir `index.html` directamente o ejecutar `python -m http.server 8000` desde esta carpeta. Para publicar en el sitio institucional, entregar la carpeta completa al equipo técnico de la UNSAAC.

## Cambios aprobados
- Logo original de la Escuela **intacto**, arriba a la izquierda.
- Escudo de la UNSAAC arriba a la derecha, enlazado desde la página oficial de UNSAAC mientras se obtiene el archivo local y autorización de uso. **Recomendación para publicar:** obtener la copia oficial autorizada y reemplazar la URL externa por `assets/escudo-unsaac.png`.
- La página se llama **Inscripciones**, no «Postulaciones».
- Cupos limitados; sin publicar cifras de cupos.
- No se solicitan antecedentes académicos, notas, currículum ni carta de motivación. Semestre/año solamente para estudiantes de pregrado.
- La Escuela no financia pasajes, alojamiento ni alimentación de asistentes.
- Sede académica FCQFM, UNSAAC, Cusco; auditorio específico por confirmar.
- Auspiciadores indicados en el proyecto final: FCQFM y Vicerrectorado Académico.
- Las cuatro fichas académicas reservan espacio para foto y ofrecen un enlace al perfil oficial. **Los monogramas FF/CG/WS/YC no son fotografías**. Para publicación, solicitar retratos autorizados y cargarlos en `assets/profesores/` tras revisar identidad y derechos.

## Formulario de inscripción
La página `inscripciones.html` muestra los campos previstos y el enlace no se habilita hasta completar `config.js` con `registrationUrl` HTTPS. Los campos deben crearse en el gestor de formularios institucional o Google Forms, no en HTML estático sin backend.
